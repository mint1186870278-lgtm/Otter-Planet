## Meshopt 候选实验

新增脚本：

```bash
npm run optimize:terrain-meshopt-candidate
```

脚本行为：

```text
1. 读取 public/model-site/scene-terrain-opt.glb。
2. 使用 Draco decoder 解码当前地形。
3. 移除 KHR_draco_mesh_compression。
4. 应用 Meshopt。
5. 校验 NURBS 节点签名，允许 0.001 以内浮点误差。
6. 输出候选到 _archive-large-source/scene-terrain-meshopt-candidate.glb。
```

实验结果：

```text
NURBS nodes preserved: 85
Draco 当前版：35.61 MB
Meshopt 候选：51.43 MB
```

结论：

```text
不能直接把当前地形从 Draco 切到 Meshopt。
在当前模型结构下，Draco 的磁盘传输体积明显小于 Meshopt 候选。
后续如果继续比较 Meshopt，应从未压缩原始模型重新导出，而不是从当前 Draco 版反转。
```
