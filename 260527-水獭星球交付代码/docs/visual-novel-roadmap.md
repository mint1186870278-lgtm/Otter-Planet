> 配套：`讲故事环节重做设计稿V2.pdf` + `docs/visual-novel-layout.md`（布局基线）
> 现状：初始态①的 UI 已重做完成；②~⑪ 全流程逻辑未接。

## 已敲定决策

1. **进度条 5 格** = 完成 ④⑥⑧⑩ 各点亮一格 + 结算第 5 格。①②③⑨ 纯过场不点亮。进度只升不降。
2. **④语音题判定走 AI**（沿用 `streamChat` 现有方案），需写 ④ 专用 system prompt。
3. **⑥⑧纯选图，本地判定**，不调 AI。设计稿 5-6 页的 kiwi 语音容错表（TV/tiwi/kivi）= 旧版遗留，忽略。
4. **⑪结算 = 占位版**：文案 + 最终星数 → `onComplete`；加星/结算动画等专门素材后补。

## 状态模型

- `step: 1–11`
- `progress: 0–5`（只升不降）
- `stars: 0–5`（只奖真实表现）
- `pickAttempts`（⑥⑧选图次数）
- `silenceCount`（沉默次数，④⑩用）

⚠️ 满星 5：给星点 ④⑥⑧⑩（4个）+ ⑪进入结算补第5颗（走完全程奖励）。✅ 已定（按实际，没走完拿不满）。

### Phase 2 — 语音题 ④（含 ⑤ 自动滑）

- AI 回复=⑤，流式播完 +1s 自动滑⑥；非两次沉默给⭐+进度+1。
- 验收：录音→动态肯定→自动进⑥。

### Phase 2 — 语音题 ④（含 ⑤ 自动滑）✅ 已完成
- 废弃旧 ASR 弹窗（黑遮罩 + 橙色大弹窗 + isOverlayActive/isSending）。✓
- 语音 UI 全部内嵌卡片：语音题标签 + 问题 + 语音条(实时识别稿) + 麦克风。✓
- 语音条用 `语音条文字框.png`；实测黄胶囊 1462×399≈3.66:1(整图1.5:1 上下透明)，固定宽×可见高 + overflow-hidden + img 105% 居中。✓
- 写 ④ system prompt `Q4_WOODPECKER_SYSTEM`：啄木鸟容错表(一只鸟/红色的鸟/敲树的鸟…) + 动态反馈(接住孩子原话) + 禁止规则，末尾 [OK]。✓
- push-to-talk：按住麦克风录音，松开(350ms后)自动发送。`recognizedText` 实时流式 = 天然蹦字效果，无需额外打字机。✓
- 松开自动发送 → AI 流式肯定(=⑤) → 播完 +1.1s 自动 advance(滑⑥)；答过给⭐+进度。✓
- 沉默兜底：松开空稿计数，第1次提示"我没听清"，第2次 advance(false) 不给⭐直接推进。✓
- 继续按钮收窄：只在 talk/result 步出现；voice 靠麦克风、affirm 自动滑。✓
- type-check 通过；语音步 ④ 渲染验证通过（puppeteer 截图：标签/问题/语音条/麦克风齐全，按钮正确隐藏）。
- ⚠️ AI 发送+自动滑链路需真麦克风，headless 无法端到端验证；逻辑已就位，待真机/手测一次。
- 遗留：⑩ 也是 voice 步，当前复用同套 UI + 临时走 MOON_GUIDE_SYSTEM；其完整故事判定([COMPLETE]/追问/沉默细则)留 Phase 4。

### Phase 3 — 选图题 ⑥⑧（本地判）✅ 已完成
- 新增三卡选图 UI + `选图题标签`。✓
- 本地判：⑥正解 `1-1`、⑧正解 `2-1`。✓
- 第一次对→⭐+进度+滑；错→提示重选（kiwi题"再想想，是啄木鸟让你去找的那个朋友～"；石头题"再看看，那个圆圆的不会发光哦～"）；两次错→揭晓答案、不给⭐、出继续手动推进。✓
- 实现细节：
  - StepDef 加 `options/answer/wrongHint` 字段；⑥⑧填好选项与提示。
  - 状态 `pickWrong`(错次)/`pickResult`(idle|right|wrong|revealed)/`pickSelected`(高亮卡)。进 pick 步在 useEffect 里重置。
  - `handlePick`：对→高亮+⭐+1.3s 自动滑；错1→提示重选；错2→揭晓正解(高亮)、不给⭐、出继续。
  - 卡片内容区 `top-[13%] bottom-[22%]`(收进气泡身体)，反馈语才不落到气泡尾巴上；卡宽 124px。
  - 继续按钮条件加 `isPickStep && pickResult==='revealed'`。
  - 进度格：对/错两次都点亮(步骤完成)；⭐只奖答对(真实表现)。
- 验收：对/错改正/两次错 三条路 puppeteer 验证通过（反馈语、⭐、继续按钮、高亮均正确）。✓
- 遗留：点对自动滑到 ⑦(affirm) 会复用"答对啦"文字——符合 affirm 保留上一步反馈的设计，暂留。
