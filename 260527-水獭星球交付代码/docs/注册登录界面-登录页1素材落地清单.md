# 注册登录界面 · 登录页 1 素材落地清单

> 范围：登录页 1 / 身份选择页。  
> 目标：中英双语共用同一套页面结构，不再维护两张整图页面；图片只承担背景、装饰、角色和质感，文字与交互尽量交给 HTML/CSS/JS。

---

## 一、当前结论

现在这批素材已经可以支撑登录页 1 的前端落地，页面可以拆成：

```text
纸张大背景
+ 顶部水獭装饰
+ 欢迎标题图 / 或真实文字标题
+ 左右两张身份卡片
  + 卡片底图
  + 角色插画
  + 中英文字图 / 或真实文字
  + 箭头按钮图
```

所有内容需要中英双版本时，不建议继续做「中文整页图」和「英文整页图」两套。正确做法是同一个 `authView = identitySelect`，根据 `lang === 'zh' | 'en'` 切换标题素材、卡片文字素材和文案字典。

## 三、中英双语映射

### 1. 标题区

```js
const titleAssets = {
  zh: '/title-welcome-otterlantis-Chinese.png',
  en: '/title-welcome-otterlantis-English.png'
}
```

标题下面的小字建议不用图片，直接由文案字典控制：

```js
const copy = {
  zh: {
    subtitle: '开始探索前，先选择你的身份'
  },
  en: {
    subtitle: 'Choose how you want to start your adventure'
  }
}
```

原因是副标题字数短、需要清晰、后续会改，使用真实文字维护成本最低。

### 2. 身份卡文字

可以暂时使用图片文字：

```js
const roleTextAssets = {
  child: {
    zh: '/我是小朋友文字.png',
    en: '/我是小朋友文字-English.png'
  },
  guardian: {
    zh: '/我是家长文字.png',
    en: '/我是家长文字-English.png'
  }
}
```

更稳的方案是只保留卡片背景和角色插画，文字全部改成 HTML。理由是图片文字在不同屏幕下会缩放变糊，英文和中文的字号、换行也不容易统一。

## 四、推荐 DOM 结构

```html
<div class="otter-auth-shell otter-auth-shell--identity">
  <img class="auth-paper-bg" src="/parchment-card-bg.png" alt="" />
  <img class="auth-header-decoration" src="/header-otter-decoration.png" alt="" />

  <section class="auth-content">
    <img class="auth-title-img" src="当前语言标题图" alt="Welcome to Otterlantis" />
    <p class="auth-subtitle">当前语言副标题</p>

    <div class="auth-role-grid">
      <button class="auth-role-card auth-role-card--child" data-role="child">
        <img class="role-card-bg" src="/role-card-child-bg.png" alt="" />
        <img class="role-card-figure role-card-figure--child" src="/child-otter-full.png" alt="" />
        <img class="role-card-text" src="当前语言小朋友文字图" alt="我是小朋友 / I'm a Kid" />
        <img class="role-card-arrow" src="/arrow-button-orange.png" alt="" />
      </button>

      <button class="auth-role-card auth-role-card--guardian" data-role="guardian">
        <img class="role-card-bg" src="/role-card-parent-bg.png" alt="" />
        <img class="role-card-figure role-card-figure--parent" src="/parent-house.png" alt="" />
        <img class="role-card-text" src="当前语言家长文字图" alt="我是家长 / I'm a Parent" />
        <img class="role-card-arrow" src="/arrow-button-blue.png" alt="" />
      </button>
    </div>
  </section>
</div>
```

这个结构保留图片质感，同时让两个身份卡仍然是真按钮，后续点击、键盘操作、埋点、响应式都能做。

## 六、当前素材还需要补的内容

登录页 1 这批素材基本够用，但全流程中英双语还缺后续页面素材或文案：

### 小朋友注册页需要

- 中文标题：`注册勇敢的水獭 ID`
- 英文标题：`Register Brave Otter ID` 或 `Create Your Otter ID`
- 中文说明：`给你的水獭取个名字。不要使用真实姓名哦。`
- 英文说明：`Give your otter a name. Please don’t use your real name.`
- 字段：`水獭昵称` / `Otter Nickname`
- 随机按钮：`随机` / `Random`
- 主按钮：`注册 ID 并开始` / `Create ID and Start`

### 家长注册页需要

- 中文标题：`注册家长 ID`
- 英文标题：`Register Parent ID`
- 字段：`显示名` / `Display Name`
- 字段：`邮箱` / `Email`
- 主按钮：`注册家长 ID` / `Register Parent ID`

这些后续页的小字、字段、按钮都建议用 HTML/CSS，不再切图。只有大标题和装饰可以继续用图片。

## 七、文件命名建议

建议把素材统一放在：

```text
public/auth-assets/
```

推荐命名：

```text
paper-identity-bg.png
header-otter-decoration.png
role-card-child-bg.png
role-card-parent-bg.png
role-child-otter.png
role-parent-house.png
arrow-orange.png
arrow-blue.png
title-identity-zh.png
title-identity-en.png
role-child-text-zh.png
role-child-text-en.png
role-parent-text-zh.png
role-parent-text-en.png
```

不要继续使用中文文件名和带括号的文件名。前端引用时中文路径、空格、括号都会增加出错概率，也不利于缓存版本管理。

## 八、落地优先级

### 第 1 步：先完成登录页 1

- 用 `parchment-card-bg.png` 做纸张外壳。
- 用 `header-otter-decoration.png` 做顶部装饰。
- 用两张 role card 背景和角色图拼出身份选择。
- 按语言切换标题图和卡片文字图。
- 点击小朋友进入 child 注册页。
- 点击家长进入 guardian 注册页。

### 第 2 步：修正中文标题素材

`title-welcome-otterlantis-Chinese.png` 需要重出真透明底，否则不要上线。

### 第 3 步：再做注册页 2 / 3

小朋友注册页和家长注册页不要整图上线，按同样思路拆：纸张背景 + 装饰插画 + HTML 表单。

## 九、给开发的简短说明

这批素材不要作为整页背景直接贴图上线。登录页 1 按组件拼装：纸张背景、顶部装饰、标题图、两张身份卡、角色图、箭头按钮分别定位。中英文通过 `lang` 切换资源和文案，不做两套 DOM。后续注册页表单保留真实 input/button，图片只做装饰。
