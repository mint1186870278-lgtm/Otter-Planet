# 注册登录界面 · 现状报告

## 一、整体架构（关键认知）

登录注册界面不是 React 组件，而是一个独立的原生 JS 浮层，游离在主应用之外：

- `public/otterlantis-auth.js`（339 行）— 全部逻辑
- `public/otterlantis-auth.css`（324 行）— 全部样式
- 通过 `index.html:13-14` 以 `<script defer>` + `<link>` 引入，缓存戳 `?v=20260622-users`

它在 `DOMContentLoaded` 时自执行：没登录就锁住页面弹浮层，登录后移除浮层、右上角显示"切换 ID"小胶囊。改这个界面只需动这两个文件，不碰 React 代码。

## 二、当前的交互流程

```
进页面 → 检查 localStorage 有无用户
  ├─ 有 → 直接进游戏 + 右上角账号切换器
  └─ 无 → 锁屏弹浮层：
        默认显示【登录】：输入水獭 ID（OT-ABCDE 格式）→ 登录
        点"没有 ID，注册一个" → 展开【注册区】，两个 Tab：
           ├─ 我是勇敢的水獭(child)：填昵称（可随机）→ 生成 ID
           └─ 我是家长(guardian)：填显示名 + 邮箱 → 生成 ID
```

浮层布局：左侧品牌区（Logo + 标语 + "每人一个唯一 ID"徽章 + 水獭蛋背景图），右侧表单卡片。移动端（≤760px）单列堆叠。

## 三、后端对接

| 动作 | 请求 | 说明 |
|------|------|------|
| 登录 | `GET /api/users/{otterId}` | 拿到就算登录成功 |
| 注册 | `POST /api/users {role, displayName, email?, lang}` | 返回 `user.otterId` |
| 埋点 | `POST /api/track` | 7 个事件（见下） |

- 后端地址硬编码：`auth.js:2` `API_BASE = "https://api.otterlantis.com"`（直连，不走 `VITE_` 环境变量 / vite proxy，和主应用的 `/api/chat`、`/api/track` 机制不一致）。
- `/api/users` 端点未写进 `backend-api-doc.md`（文档只覆盖 `/api/track`），属于隐性契约。
- 存储：localStorage 的 `otterlantis_user` + `otterlantis_session_id`。
- 埋点事件：`auth_modal_view` / `auth_register_open` / `user_login` / `user_create` / `game_start_after_register` / `user_switch`。

## 四、要改之前必须知道的几个问题点

1. **"登录"没有任何密码/凭证** — 只要输入别人的 OT-ID 就能登进别人账号。ID 短（OT-ABCDE），是可猜的。这是当前设计（面向儿童、无密码），但如果新界面涉及家长/隐私要重新评估。
2. **无参数时语言会不一致** — auth 的 `getLang()` 在无 `?lang` 时回退到 `document.documentElement.lang`，而 `index.html:2` 是 `<html lang="en">` → 默认弹英文登录框；但 React 主应用无参数时默认中文。裸访问会"登录框英文、游戏中文"。改版时建议统一。
3. **家长注册是半成品** — 文案自己写着"第一版先记录邮箱，验证码下一步接入"（`auth.js:165`），邮箱不校验格式、不验证。
4. **纯 localStorage 无会话过期** — 没有 token/时效，清缓存即登出。
5. **视觉风格自成一套** — 用的是 Nunito 字体 + 硬编码色值（`#ff9800` 橙、`#14527b` 蓝），和 React 端 Tailwind 的 `otter-orange` 等设计 token 不共享。改版若要统一风格，这套 CSS 得对齐。

## 五、建议的改版信息

告诉我你这次想改的方向，我好定方案（都只需动那两个文件）：

- **视觉重做**（换布局/配色/文案，逻辑不动）— 最轻，低风险
- **流程调整**（比如登录注册合并、Tab 顺序、默认页）
- **补功能**（家长邮箱验证码、ID 找回、密码/PIN）— 需后端配合，得先确认 `api.otterlantis.com` 支持哪些端点
- **统一到 React**（把浮层迁进主应用，共享 Tailwind 设计）— 改动最大
