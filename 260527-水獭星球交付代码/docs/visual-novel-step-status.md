## 当前流程总览

```
① talk → ② talk → ③ talk → ④ voice → ⑤ affirm → ⑥ pick → ⑦ affirm → ⑧ pick → ⑨ talk → ⑩ voice → ⑪ result
```

- **进度条点亮**：完成 ④⑥⑧⑩ 各+1格，⑪结算+1格（共5格，只升不降）。
- **⭐给星**：④语音作答、⑥⑧选图答对、⑩讲故事各+1（=4），**⑪进入结算再+1（走完全程奖励）= 满5**。沉默兜底/选图两次错 → 不给⭐但照常推进。
- **推进方式（已改：每步答完都停在「继续」按钮等用户点）**：
  - talk/result = 打字机播完出继续按钮点击。
  - voice④⑩ = 麦克风录音 → AI 回复就地显示 + 继续按钮（不再自动滑）。
  - pick⑥⑧ = 答对显示肯定句 + 继续按钮（不再自动滑）；两次错揭晓答案 + 继续按钮。
  - **affirm⑤⑦ 已并入答题步**（方案a）：肯定句就是 ④的AI回复 / ⑥⑧的 `affirmText`，在答题步显示；`advance()` 推进时跳过紧随的 affirm 步，不单独成屏、不重复、不连点两次按钮。
