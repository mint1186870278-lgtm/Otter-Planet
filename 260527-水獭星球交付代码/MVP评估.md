# 水獭星球跑酷场景 — MVP 重构评估（八向 + 固定相机简化版）

> 评估日期：2026-05-30
> 基于 [重构方案.md](重构方案.md) 在简化前提下重新核算；现状分析见 [重构评估.md](重构评估.md)。
> 涉及文件：[src/components/ParkourScene.tsx](src/components/ParkourScene.tsx)、[src/components/SectionParkour.tsx](src/components/SectionParkour.tsx)
> 不改任何代码，仅评估。

## 简化前提

| 项 | 约定 |
|---|---|
| 移动控制 | **只用键盘方向键 ↑↓←→**，世界轴八向移动 |
| 轴向映射 | ↑ = 向前（-z）、↓ = 向后（+z）、← = 左（-x）、→ = 右（+x） |
| 不用 WASD | 单套键映射 |
| 玩家朝向 | 只跟移动方向**简单翻转**，不做平滑转身 |
| 相机 | **固定偏移跟随**，不随朝向旋转 |

### 这三条简化精准砍在原方案最贵的地方
| 简化 | 砍掉的复杂度 |
|---|---|
| 只用方向键 ↑↓←→ | 无 WASD 双套键映射；不用设计"前进+转向"备选模型 |
| 世界轴八向 | 输入**直接**映射成 `{vx, vz}`，**无需相机相对变换/旋转矩阵/三角函数** |
| 朝向只简单翻转 | 无 heading 角度维护、无 lerp/slerp 转身插值 |
| 相机固定偏移 | 无"偏移向量绕 heading 旋转"——原方案阶段②唯一的难点 |

一句话：**原方案里所有跟"朝向/转身/镜头旋转"耦合的部分全部消失**，剩下的是相对机械的"连续坐标 + 平移跟随 + 距离判断"。

---

## 1. 阶段⑤ 删什么，剩什么

### 直接删除（被简化前提排除）
- ❌ **玩家转向（平滑转身）** —— 改为简单翻转，并入阶段①，不再是独立打磨项
- ❌ **相机随朝向旋转（镜头绕到背后）** —— 固定偏移已满足，整项删除

> 这两项是原阶段⑤的"进阶/手感"核心，也是阶段②的进阶项。删掉后，阶段⑤不再含任何"移动/相机"相关工作。

### 删完后阶段⑤剩下的（都属纯收尾，与移动范式无关）
1. 地图边界 / 隐形墙（防走出地形）
2. 移动端按钮 → 虚拟摇杆 / 四向键
3. `ParkourScene` props 接口清理（删 `lane/laneRef/terrainSpeed/obstacleSpeed`）
4. 常量清理（`LANE_SPACING`/`TERRAIN_LENGTH`/`SCENE_SPEED` 等）
5. 问号箱（如需，补全从未实现的 `'question'` 类型）
6. 关闭 `DEBUG_MODE` + debug 面板
7. `tsc --noEmit` 类型检查

**剩下的全是"可选/锦上添花"，没有一项是跑起来必需的** —— 这正是下面 MVP 能整段跳过⑤的原因。

## 2. 阶段①② 简化了多少

### 阶段① — 从「中→大」降到「中（偏小）」
| 原方案要做 | 简化后 |
|---|---|
| 八向 **或** "前进+转向"二选一，需先定方案 | 唯一确定：八向世界轴，无需选型 |
| 输入 → 速度向量（含 WASD） | `↑/↓→vz`、`←/→→vx`，**几行 if 直给**，无 WASD |
| 朝向随移动方向**平滑旋转**（维护 heading + 插值） | `atan2(vx,vz)` 直接 set `rotation.y`，**无插值** |
| playerPos ref + 每帧积分 + Character 绑定 + 动画开关 | **保留**（地基，省不掉） |

省掉：键映射量、转向选型、heading 平滑插值。**保留的地基**（真实坐标 ref、位移积分、Character 位置绑定、动画 play/pause 条件）动不了——这是整个改造的承重墙。
→ 估计工作量减约 **30~40%**。

### 阶段② — 从「中」降到「小」
| 原方案 | 简化后 |
|---|---|
| 跟随 + lerp 阻尼 | 保留（可选，甚至先不做也能跑） |
| **进阶：偏移向量绕 heading 旋转**（②唯一难点） | **整项删除** |

简化后阶段②基本是：`camera.position = playerPos + {0,5.5,11}; camera.lookAt(playerPos)` —— 把现有固定相机平移成跟随，**约 10 行，无三角运算**。
→ 估计工作量减约 **50~60%**，从"中"实质降为"小"。

## 3. 重新核算每阶段 + 总评估

| 阶段 | 原评级 | 新评级 | 大致改动量 | 说明 |
|---|---|---|---|---|
| 0 准备基线 | 小 | **小** | 备份 + 录基线 | 不变 |
| ① 玩家坐标 + 八向 + 翻转 | 中→大 | **中** | SectionParkour 输入区 [88-128] 重写 + Character [109-177] 改写 + 新增 playerPos ref/积分 | 砍了转身插值/WASD/选型 |
| ② 相机固定跟随 | 中 | **小** | CameraRig [436-445] ~10 行重写 | 砍了镜头绕朝向旋转 |
| ③ 物体固定坐标 | 中 | **中** | 星星/NPC/障碍/地形 去滚动 + `{lane,z}`→`{x,z}` + 数据重排 | 基本不变（机械改 + 数据设计） |
| ④ 2D 碰撞 | 中 | **小→中** | 三处距离判定改写，各几行 | 与朝向无关，不受简化影响，模式统一简单 |
| ⑤ 收尾打磨 | 中 | **小（且整段可选）** | 见 §1 剩余 7 项 | 移动/相机相关已全删 |

### 总评估
- **ParkourScene.tsx**：原 ~70% 大改 → 现 **~55% 中改**（移动/相机的旋转复杂度移除，但物体/地形/碰撞照旧要动）
- **SectionParkour.tsx**：原 ~20% → 现 **~15%**（输入区更简单，UI 八成照旧）
- **整体：从「大」降到「中」。** 承重墙（玩家真实坐标系）仍在，但围绕它的"转身 / 镜头旋转"两层难度被剥掉，落地路径明显变直。

## 4. 最小可玩重构版本（MVP）

**范围**：方向键八向走 + 相机跟随 + 物体固定坐标 + 2D 碰撞 + NPC 触发对话。
**明确不做**：边界墙、移动端控制、问号箱、props/常量清理、转身插值、镜头旋转、Git LFS 等全部跳过。

### MVP 实际要碰的地方

**ParkourScene.tsx**
| 位置 | 改动 | 量级 |
|---|---|---|
| `Character` [109-177] | 接 playerPos，`position.set(x,0,z)`，删车道 lerp，朝向 `atan2` 直接 set，动画按速度开关 | **中** |
| `CameraRig` [436-445] | 固定偏移跟随，~10 行 | **小** |
| `TerrainTile/Model` [15-65] | 删滚动 useFrame + 循环，**保留单块静态地形**（120×120 自动缩放，直接当 MVP 地图，**不需要新美术**） | **小** |
| 星星 [187-243, 390-409] | `{lane,z}`→`{x,z}`，删 StarsGroup 滚动，15 颗重排进 ~120 范围 | **小→中** |
| NPC [305-387] | 坐标改世界 `{x,z}`，删 NpcGroup 滚动 + 删"passed 后消失" | **小** |
| 障碍 [266-302] | **决策点**：最省事先注释掉定时生成；建议放 3~5 个固定障碍，顺带验证 2D 命中 | **小** |
| 2D 碰撞 [232][284][347] | 星星收集 / 障碍命中 / NPC 接近 三处改平面距离 | **小** |
| DebugNpcTracker [414-433] | NPC 固定后直接报静态坐标或删掉 | **小** |
| props | 只加 playerPos，暂留旧字段不清理 | **微** |

**SectionParkour.tsx**
| 位置 | 改动 | 量级 |
|---|---|---|
| 输入区 [88-128] | `position(-1/0/1)`+`forwardSpeed` → playerPos ref + `{vx,vz}`，只认方向键 | **中** |
| 透传 props [474-488] | 传 playerPos | **微** |
| debug 面板 PlayerZ [502] | 读真实坐标 | **微** |
| HUD/对话/气泡/计分/里程碑/`handleNpcApproach` A/B/C 判断 [175-201] | **全部不动** | **零** |

### MVP 工作量评估：**中（偏小）**

- 改动集中在 **2 个文件、约 8~10 个点**，其中只有 2 处是"中"（玩家移动地基 + 输入重写），其余全是"小/微"。
- **零新美术**（复用现有地形 tile）、**零新依赖**、**UI 层零改动**。
- 关键依赖链清晰：**玩家坐标（①）是唯一地基，打通后②③④顺势而下**，且彼此可分步独立验证。
- 粗略量级：对熟悉这套代码的人，**约 1~2 个集中工作日**（实现 + 在 3D 里反复调位置/手感），主要时间花在星星/NPC 坐标手摆和 3D 调试，而非逻辑难度。

### 风险提示（不影响评级，但 MVP 阶段要心里有数）
1. **星星坐标重排**是手工活：15 颗摆到 120×120 地图里好不好玩，要在 3D 里反复试——MVP 里最耗时但最不"难"的部分。
2. **地形够不够大**：单块 120×120 当 MVP 地图够用；真要更大地图是后续美术工作，MVP 不碰。
3. **障碍决策点先定**：首版建议"几个固定障碍"，别再用定时滚动生成（会和去滚动冲突）。

## MVP 落地顺序（精简版）

沿用 [重构方案.md](重构方案.md) 的依赖链，但只做必需项：

```
① 玩家坐标 + 八向 + 朝向翻转   ← 地基，唯一的「中」难点
② 相机固定偏移跟随            ← ~10 行
③ 地形去滚动 + 星星/NPC/障碍钉世界坐标
④ 三处碰撞改 2D 平面距离      ← NPC 接近触发对话（A/B/C 判断复用）
（⑤ 打磨整段跳过）
```

每步做完都应是"能跑的半成品"，逐步验证，不跨步同时改多处。
