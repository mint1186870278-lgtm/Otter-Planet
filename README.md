# Otter Planet（水獭星球）

按「日期版本文件夹」组织的项目仓库。每个顶层文件夹是一个可独立运行的版本快照，方便区分版本、回溯历史。

## 版本

| 版本文件夹 | 说明 |
|---|---|
| [`260527-水獭星球交付代码/`](./260527-水獭星球交付代码/) | 当前最新版（截至 2026-07-01）。含跑酷 / 讲故事 / 相册留存等完整功能，及一轮耦合/热更治理与若干修复。 |

> 以后每交付一版，就在根目录新增一个 `YYMMDD-...` 的版本文件夹，本表追加一行。

## 每个版本文件夹里有什么

「干净快照」：源码 + `public/` 运行素材。**不含** `node_modules/`、`dist/` 构建产物、交付 `*.zip`、`.env` 密钥（这些由根 `.gitignore` 统一排除）。

## 本地运行

```bash
cd 260527-水獭星球交付代码
npm install
npm run dev        # http://localhost:3000
```

## 说明

- 版本区分靠「文件夹」，不靠 zip；历史大二进制（交付 zip、Blender 母文件等）不入库，另行归档。
- 每个版本文件夹内另有自己的 `README` / 交付文档，记录该版细节。
